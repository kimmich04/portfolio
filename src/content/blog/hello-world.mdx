This is my first post. Posts live in `src/content/blog/` as Markdown (`.md`) or MDX (`.mdx`) files.

## What to write about

- Things you learned during a project or internship
- Write-ups of bugs you solved
- Notes on tools and technologies you're exploring

Because this is MDX, you can also import and use Astro components right inside a post.

```ts
const greet = (name: string) => `Hello, ${name}!`;
```

Set `draft: true` in the frontmatter to hide a post until it's ready.
